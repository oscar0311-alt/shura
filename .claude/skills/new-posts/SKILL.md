새 게시물 초안 $ARGUMENTS 개를 만든다. 숫자가 없으면 7개.

1. `CLAUDE.md`의 문구 기준, `used_phrases.txt`, `posts.json`의 기존 게시물을 먼저 읽는다.
2. 후보 라틴어를 필요한 개수의 2배 정도 떠올린 뒤, 금지 목록·중복·출처 불확실한 것을 걸러내고 남은 것 중에서 고른다.
3. 주제가 한쪽으로 몰리지 않게 섞는다: 규율 / 집착 / 고통과 단련 / 시간 / 기준과 타협 / 고독.
4. 각 게시물을 CLAUDE.md 형식대로 `posts.json` 끝에 status "draft"로 추가한다.
5. 고른 라틴어를 `used_phrases.txt` 끝에 추가한다.
6. `python render.py --video`를 실행하고, 새로 만든 이미지를 하나씩 열어 글자가 넘치지 않는지 확인한다. 넘치면 문구를 고치고 `--all` 없이 해당 파일을 지운 뒤 다시 렌더링한다.
7. 마지막에 새 게시물 목록(id, 라틴어, 한국어 번역, 본문 첫 줄)을 표로 보여준다.
